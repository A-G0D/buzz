# Research map

Check local project notes and source files before browsing. For unstable,
niche, or consequential claims, verify against current primary sources and cite
them. Record the publication date, what the source measured, and what it did not
establish. Distinguish a preprint, a benchmark result, and a production fact.

## Skill route

- Use an installed retrieval/research skill only if its scope fits the actual
  question and its provenance is known.
- Do not install a search skill just because research was requested; the active
  tools may already cover the task.
- A reusable research procedure should specify source-quality checks, query
  scope, citation handling, and a paired evaluation against direct research.
- Leave uncertain sources or unsupported metrics out of the skill's claimed
  behavior. Keep source links and version history with any proposed skill.
